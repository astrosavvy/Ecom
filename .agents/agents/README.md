# AI Specialist Agent Roster & Delegation Matrix

To prevent cross-domain contamination and ensure surgical code modifications, the repository defines 3 specialist agent roles:

| Agent Persona | Owned Directories | Key Responsibilities |
|---|---|---|
| **Storefront Agent** | `younoya-web/` | React 19 UI, CSS tokens, scroll film stage, components, Vite build |
| **Commerce Backend Agent** | `backend/` | Medusa 2.18, PG15, Redis, OTP modules, API routes, migrations |
| **Creative Media Agent** | `creative/younoya-scroll-film/` | Lets-scroll film chain, prompt engineering, seam QA, stills |

When planning multi-step features, designate the responsible specialist persona for each task.
